# **App Name**: FreshHarvest Direct

## Core Features:

- Landing Page with Dynamic Price Calculator: Interactive landing page to display subscription options with a price calculator that adjusts based on the quantity of items per day, updating in real time.
- User Authentication: Secure user authentication using Firebase Auth with email/password and Google Sign-In, storing minimal user details and a subscription reference.
- Customer Dashboard: A clean and simple dashboard providing customers with active subscription details, quick access to profile management, and the ability to easily manage and update their subscription plans.
- Subscription Plan Recommendation: Suggest a relevant plan (itemsPerDay, price, startDate, activeStatus, userRef) for the user with a tool using recent sales metrics and customer profiles to personalize recommendations.

## Style Guidelines:

- Primary color: Vibrant green (#5CB85C) to evoke freshness and health, reflecting the essence of fruits and vegetables. This color is not overwhelming and works well on a white background.
- Background color: Light green (#F0FAF0), providing a clean and subtle backdrop that complements the primary green without causing distraction.
- Accent color: Warm yellow (#FFC107) to highlight key interactive elements and calls to action, ensuring they stand out without clashing with the primary and background colors.
- Font pairing: 'Poppins' (sans-serif) for headlines and short, punchy blocks of text. 'PT Sans' (sans-serif) for longer stretches of text in the body, providing an enjoyable reading experience.
- Use simple, outlined icons to represent different fruits, vegetables, and delivery actions.
- A clean, grid-based layout to ensure content is well-organized and responsive across all devices.
